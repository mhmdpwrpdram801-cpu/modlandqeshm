# مهاجرت‌ها

هر بار که دستورالعمل تغییری می‌کند که **کدِ موجود را نامنطبق می‌کند**، اینجا یک ورودی
می‌گیرد. بدونِ ورودی، نسخه بالا نمی‌رود (SELF-02).

`/gl-migrate` همین فایل را می‌خواند: از نسخه‌ی مُهرخورده در `guidelines/lock.json` تا
نسخه‌ی فعلی، ورودی‌ها را **به ترتیب** و **یکی‌یکی** اجرا می‌کند (MIG-02).

---

## قالبِ هر ورودی — دقیقاً همین ساختار

````markdown
## 2026.08.1 → 2026.09.1

**سطح:** اجباری | پیشنهادی | اختیاری
**قاعده‌ها:** SEC-06، DATA-04
**علت:** یک جمله — چه چیزی عوض شد و چرا.

### چه کسانی درگیرند
فرمانی که خودش می‌گوید این پروژه درگیر هست یا نه. باید کدِ خروجی بدهد:
```bash
rg -l "localStorage.setItem\(['\"]token" --type ts
```
اگر خروجی خالی بود، این مهاجرت برای این مخزن بی‌ربط است — رد شو و مُهر را جلو ببر.

### چطور مهاجرت کن
گام‌های دقیق و کوچک. اگر خودکارشدنی است، اسکریپتش را بگذار.

1. ...
2. ...

### چطور وارسی کن
فرمانی که **قبل** از مهاجرت می‌افتد و **بعد** از آن پاس می‌شود.
```bash
python3 guidelines/self-check.py && <دروازه‌ی وارسیِ پروژه>
```

### خطر و راهِ برگشت
چه چیزی ممکن است بشکند و چطور برگردانده می‌شود.
````

**سطح‌ها:**

| سطح | یعنی | رفتارِ `/gl-migrate` |
|-----|------|---------------------|
| **اجباری** | درستی، امنیت، داده یا دسترس‌پذیری درگیر است | اجرا می‌کند (بعد از تأییدِ کاربر) |
| **پیشنهادی** | کیفیت یا نگه‌داری بهتر می‌شود، ولی چیزی خراب نیست | فهرست می‌کند، اجرا نمی‌کند مگر بخواهی |
| **اختیاری** | سلیقه، سبک، انتخابِ فناوری | فقط نام می‌برد (MIG-04) |

## 2026.08.3 → 2026.08.4 (CLAUDE.md برای نصب‌های قدیمی)

**سطح:** پیشنهادی
**قاعده‌ها:** ACT-01
**علت:** پروژه‌هایی که پیش از این نسخه نصب شده‌اند `CLAUDE.md` ندارند، پس
دستورالعمل در حافظه بار نمی‌شود و فعال‌سازی فقط به هوک تکیه دارد.

### چه کسانی درگیرند
```bash
grep -q 'guidelines/FULLSTACK.md' CLAUDE.md 2>/dev/null || echo "درگیر است"
```

### چطور مهاجرت کن
نصاب را دوباره اجرا کن — بی‌خطر است و چیزی را خراب نمی‌کند:

```bash
curl -fsS https://raw.githubusercontent.com/mhmdpwrpdram801-cpu/modlandqeshm/main/guidelines/install.py | python3 -
```

`lock.json`ِ موجود دست نمی‌خورد، `settings.json` ادغام می‌شود، و `CLAUDE.md`ِ
موجود فقط یک بلوک اضافه می‌گیرد (رونویسی نمی‌شود).

### چطور وارسی کن
```bash
grep -c 'guidelines/FULLSTACK.md' CLAUDE.md   # باید ۱ باشد
python3 guidelines/self-check.py
```

### خطر و راهِ برگشت
فایلِ موجود رونویسی نمی‌شود. برگشت: بلوکِ بینِ نشانه‌های `GUIDELINE-IMPORT` را بردار.

## 2026.08.1 → 2026.08.2 (به‌روز ماندنِ کپی‌ها)

**سطح:** پیشنهادی
**قاعده‌ها:** SELF-05، MIG-07
**علت:** تا اینجا `lock.json` می‌گفت «کدِ من از دستورالعمل عقب است»، ولی هیچ‌چیز
نمی‌گفت «دستورالعملِ من از منبع عقب است». پروژه‌ای که این بسته در آن کپی شده بود،
جدا کهنه می‌شد و کسی خبردار نمی‌شد.

> **این یکی را نمی‌شود خودکار گرفت.** پروژه‌ای که `gl-update.py` ندارد، نمی‌تواند
> نسخه‌ای را بگیرد که خودِ `gl-update.py` در آن است. پس **فقط این بار** دستی است؛
> از این به بعد خودکار می‌شود.

### چه کسانی درگیرند
```bash
test -f guidelines/gl-update.py || echo "درگیر است"
```
خروجی خالی بود یعنی از قبل دارد — رد شو.

### چطور مهاجرت کن

یک فرمان — بقیه‌اش خودکار است:

```bash
curl -fsS https://raw.githubusercontent.com/mhmdpwrpdram801-cpu/modlandqeshm/main/guidelines/install.py | python3 -
```

نصاب کلِ بسته را می‌گیرد، هوک را در `.claude/settings.json` **ادغام** می‌کند (تنظیماتِ
موجود را خراب نمی‌کند)، گردش‌کارِ هفتگی را می‌گذارد، `.gitignore` را به‌روز می‌کند و
آخرش خودوارسی می‌گیرد.

`lock.json`ِ موجود دست نمی‌خورد. اگر نبود، نصاب یکی می‌سازد و دروازه‌ی وارسی را از روی
خودِ پروژه پر می‌کند (`package.json` → `npm run test/lint`، یا `pyproject.toml` → pytest).

**هیچ تنظیمِ دستی‌ای لازم نیست:** `is_origin` روی `auto` است و از روی remoteهای گیت
خودش می‌فهمد اینجا کپی است نه منبع.

### چطور وارسی کن
```bash
python3 guidelines/gl-update.py     # باید نسخه‌ی محلی و منبع را نشان بدهد
python3 guidelines/self-check.py    # باید سبز باشد
```
قبل از مهاجرت، فرمانِ اول اصلاً وجود ندارد؛ بعدش کار می‌کند.

### خطر و راهِ برگشت
هیچ فایلِ موجودی جز هوک عوض نمی‌شود و هوک هم رو به عقب سازگار است (اگر
`gl-update.py` نباشد، بخشِ منبع را اصلاً اجرا نمی‌کند). برگشت: حذفِ همان چهار فایل.
