# سایتِ فراری F40

یک صفحه‌ی معرفیِ کاملِ فراری F40 — فارسی، راست‌به‌چپ، موبایل‌محور، با تمِ روشن و تاریک.

> این پوشه **هیچ ربطی به پنلِ مدلند قشم ندارد** و روی سرورِ پنل نمی‌رود.
> گردش‌کارِ انتشار (`.github/workflows/deploy.yml`) فقط با تغییر در `panel/`،
> `wrangler.toml` یا خودِ گردش‌کار اجرا می‌شود، و ورکر هم فقط پوشه‌ی `panel/`
> را سرو می‌کند. پس اضافه‌شدنِ این پوشه چیزی را منتشر یا خراب نمی‌کند.

## فایل‌ها

```
index.html          کلِ سایت — HTML + CSS + JS در یک فایل، بدونِ فریم‌ورک و بدونِ build
font1/2.woff2       وزیرمتن ۴۰۰ و ۷۰۰ (کپیِ همان فونتِ پنل، تا سایت آفلاین هم درست باشد)
audit.config.json   تنظیماتِ بازرس برای همین سایت — ۲۳ بررسیِ اختصاصی
```

## اجرا

فایلِ ساده‌ی ایستاست؛ هر سروری کافی است:

```bash
python3 -m http.server -d f40 8000     # بعد برو http://127.0.0.1:8000
```

باز کردنِ مستقیمِ `file://` هم کار می‌کند، فقط فونت‌ها ممکن است بار نشوند.

## دروازه‌ی وارسی

```bash
python3 auditor/audit.py f40/index.html -c f40/audit.config.json          # کرومیوم
python3 auditor/audit.py f40/index.html -c f40/audit.config.json -e webkit # موتورِ سافاری
python3 auditor/audit.py f40/index.html -c f40/audit.config.json -r 3      # تکرارپذیری
```

کدِ خروجی ۰ یعنی آماده. آخرین اندازه‌گیری: کرومیوم **۴۹ پاس، ۰ ایراد**، و هر ۲۳
بررسیِ اختصاصی در ۳ دورِ پشتِ‌سرِهم نتیجه‌ی یکسان.

## ساختارِ صفحه

| بخش | چه دارد |
|-----|---------|
| قهرمان | چهار عددِ کلیدی با شمارنده + نقاشیِ نمای جانبی |
| داستان | ریشه در ۲۸۸ GTO، ۱۳ ماه تا رونمایی، آخرین امضای انزو |
| مشخصات | چهار کارتِ عدد + جدولِ کاملِ فنی (۲۱ ردیف) |
| موتور | نوارهای F120A + سه کارتِ توضیحی |
| طراحی | پینین‌فارینا، ۱۱ قطعه‌ی کولار/کربن، فهرستِ «چه چیزهایی نگذاشتند» |
| خطِ زمان | ۱۹۸۴ تا امروز، هشت ایستگاه |
| مسابقه | LM، GTE، GT |
| مقایسه | نمودارِ تعاملی با پنج معیار در برابرِ ۲۸۸ GTO، F50، انزو، لافراری |
| نماها | چهار نقاشیِ برداری: جانبی، جلو، عقب، بالا |
| نکته‌ها | شش حاشیه‌ی کمتر گفته‌شده |

## قاعده‌هایی که موقعِ دست‌زدن به این فایل بشکن نده

- **نردبانِ z-index نام‌دار است، از آن خارج نشو:**
  محتوا ۰ · هنرِ پس‌زمینه ۱ · نوارِ بالا ۳۰ · پرده‌ی منو ۴۰ · لینکِ پرش ۴۵ ·
  منوی موبایل ۵۰ · پنجره ۶۰ · پیامِ شناور ۸۰.
  بازرس هر چیزی که بالاتر از کشو بنشیند را می‌گیرد — لینکِ «پرش به محتوا» یک بار
  روی ۸۰ بود و گیر افتاد.
- **کشو با `translateX(-100%)` پنهان می‌شود، نه `+100%`.** صفحه RTL است و
  `inset-inline-end` لبه‌ی **چپِ فیزیکی** است؛ با مقدارِ مثبت، کشوی «بسته» وسطِ صفحه
  می‌ماند و لمسِ دکمه‌ها را می‌دزدد. بازرس همین را گرفت (چهار دکمه‌ی مسدود).
  `visibility:hidden` هم لازم است تا در حالتِ بسته فوکوس داخلش نرود.
- **هیچ رنگِ ثابتی ننویس.** هر رنگ یک متغیرِ CSS است و باید در `:root` و
  `html[data-theme="dark"]` **هر دو** تعریف شود. دو بررسیِ خودکار هر متغیرِ
  استفاده‌شده را در هر دو تم می‌سنجد.
- **زمینه‌ی کارت‌ها از `--panel-2` می‌آید، نه `--bg-2`.** بخش‌ها یک‌درمیان زمینه‌شان
  عوض می‌شود؛ اگر کارت رنگِ ثابت بگیرد، در نصفِ بخش‌ها هم‌رنگِ زمینه و نامرئی می‌شود.
  یک بررسیِ خودکار دارد.
- **آفستِ منفی روی عنصرِ تزیینی در RTL کشوی افقی می‌سازد.** دایره‌ی محوِ هیرو یک بار
  `inset-inline-end:-10%` داشت و در ۳۲۰ پیکسل ۳۲ پیکسل کشو درست کرد. `overflow:hidden`
  پنهانش می‌کند ولی حذفش نمی‌کند.
- **`window.F40` قلابِ تست است، نه API عمومی.** بازرس از آن استفاده می‌کند تا
  به‌جای صدا زدنِ توابعِ داخلی وضعیتِ واقعی را بخواند. اگر تابعی را عوض کردی،
  این قلاب را هم به‌روز کن وگرنه بررسی‌ها بی‌صدا بی‌معنی می‌شوند.
- **در `audit.config.json`، `scrollTo` باید `behavior:'instant'` باشد.** صفحه
  `scroll-behavior:smooth` دارد و اسکرولِ انیمیشنیِ `reset` با اسکرولِ خودِ بررسی
  مسابقه می‌داد — چند عکس از وسطِ بخشِ دیگری درآمد و اول به‌نظر باگِ چیدمان می‌رسید.
- **بررسیِ ظهورِ نرم:** عنصرهای `.reveal` تا وقتی به دید نیایند `opacity:0`اند و از
  اندازه‌گیریِ رنگ و بیرون‌زدگی جا می‌مانند. برای همین `reset` بازرس
  `window.F40.revealAll()` را صدا می‌زند. هر بررسیِ تازه‌ای هم که به چیدمان کار دارد
  باید همین کار را بکند.

## درباره‌ی داده‌ها و تصویرها

- ارقام از مشخصاتِ عمومیِ منتشرشده‌ی این خودرو گرفته شده‌اند. جایی که منابع
  اختلاف دارند (مثلاً تعدادِ تولید ۱۳۱۱ در برابرِ ۱۳۱۵) در پاورقیِ خودِ صفحه گفته شده.
- **هیچ عکسی از اینترنت برداشته نشده.** هر چهار نما نقاشیِ برداریِ اختصاصیِ همین
  صفحه‌اند که از روی ابعادِ واقعی (طول ۴۴۳۰، فاصله‌ی محورها ۲۴۵۰، ارتفاع ۱۱۳۰
  میلی‌متر) با مقیاسِ ۰٫۱۷ پیکسل بر میلی‌متر کشیده شده‌اند. رنگ‌هایشان هم از
  متغیرِ CSS می‌آید، پس با تم عوض می‌شوند.
- «فراری» و «F40» نام‌های تجاریِ متعلق به مالکانِ خودشان هستند؛ این صفحه غیررسمی
  و آموزشی است.
