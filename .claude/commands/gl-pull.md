# گرفتن از منبع

دامنه: `$1` (پیش‌فرض `docs`)

- `docs` — فقط متن و داده: `FULLSTACK.md`، `MIGRATIONS.md`، `CHANGELOG.md`، `stack.json`، دستورها.
- `all` — اسکریپت‌ها و هوک را هم به‌روز می‌کند (`--with-tools`).

این دستور جوابِ «کپیِ دستورالعملِ من از منبع عقب افتاده» است. جوابِ «کدِ من از
دستورالعمل عقب افتاده» `/gl-migrate` است — و معمولاً بعد از این یکی لازم می‌شود.

## کارها

1. **اول بسنج، بعد بنویس:**
   ```bash
   python3 guidelines/gl-update.py
   ```
   کدِ خروجی: `0` به‌روز · `1` نسخه‌ی تازه‌تری هست · `3` خطا (شبکه/پیکربندی).
   اگر `0` بود: بگو «دستورالعمل به‌روز است» و **تمام**. چیزی را دستکاری نکن.
   اگر `3` بود: خطا را نشان بده. حدس نزن که چه چیزی عقب است.

2. **درختِ کار تمیز باشد.** اگر `git status` تمیز نیست، بایست و از کاربر بخواه
   اول کارِ نیمه‌تمامش را کامیت کند — وگرنه اگر چیزی خراب شد، جدا کردنِ
   تغییرِ منبع از تغییرِ خودش ممکن نیست.

3. **فهرستِ تغییرها را نشان بده و اجازه بگیر.** به‌ویژه اگر `all` خواسته شده:
   اسکریپت و هوک **کدِ اجرایی**اند و از اینترنت می‌آیند. کاربر باید بداند.

4. **بگیر:**
   ```bash
   python3 guidelines/gl-update.py --apply            # docs
   python3 guidelines/gl-update.py --apply --with-tools   # all
   ```

5. **فایلِ دست‌کاری‌شده را زورکی رونویسی نکن.** اگر گزارش داد «محلی عوض شده»،
   همان‌جا بایست و به کاربر بگو کدام فایل و چه فرقی دارد. `--force` فقط با
   خواستِ صریحِ او.

6. **وارسی کن:**
   ```bash
   python3 guidelines/self-check.py
   ```
   قرمز شد، همان‌جا بایست — بستهٔ نیم‌کاره بدتر از بسته‌ی کهنه است.

7. **کامیتِ جدا** فقط برای همین به‌روزرسانی:
   ```
   guideline: گرفتنِ نسخه‌ی <نسخه> از منبع

   <خلاصه‌ی تغییرهای CHANGELOG>
   مُهر عوض نشد؛ مهاجرت جدا انجام می‌شود.
   ```

8. **`lock.json` را دست نزن** (MIG-07). حالا `FULLSTACK.md` جلوتر از مُهر است و
   همین درست است — یعنی مهاجرت معلق داری.

9. `CHANGELOG.md`ِ تازه را بخوان و به کاربر بگو **چه چیزی عوض شده و آیا مهاجرت
   لازم است**. اگر بله، پیشنهاد بده `/gl-migrate` بزند.

## قاعده‌ها

- **جهت یک‌طرفه است:** منبع → پروژه. هیچ‌وقت از پروژه به منبع چیزی برنگردان (SELF-05).
  اگر اینجا قاعده‌ای بهتر شد، در خودِ مخزنِ منبع با `/gl-sync` واردش کن.
- **در خودِ مخزنِ منبع این دستور بی‌اثر است** (`source.json` → `is_origin`). آنجا
  `/gl-sync` کارِ درست است.
- گرفتنِ نسخه‌ی تازه **مُهر را جلو نمی‌برد**. آن کارِ `/gl-migrate` است، آن هم فقط
  بعد از سبز شدنِ وارسی (MIG-06).
