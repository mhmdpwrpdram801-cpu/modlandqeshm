# به‌روزرسانیِ دستورالعمل

حالت: `$1` (پیش‌فرض `versions`)

- `versions` — فقط شماره‌ی نسخه‌ها. سریع، مکانیکی، کم‌خطر.
- `full` — بازنگریِ محتوایی هم: آیا قاعده‌ای کهنه شده؟ چیزی جا مانده؟

## ۱. وضعیتِ فعلی

```bash
python3 guidelines/check-drift.py
python3 guidelines/self-check.py
```
کدِ خروجیِ drift: `0` به‌روز · `1` عقب‌افتادگیِ کوچک · `2` پرشِ نسخه‌ی اصلی · `3` خطای شبکه.
اگر هر دو سبز بودند و حالت `versions` است: بگو «دستورالعمل به‌روز است» و **تمام**.
نسخه را الکی بالا نبر.

## ۲. نسخه‌ها

- عقب‌افتادگیِ **کوچک** → `python3 guidelines/check-drift.py --write`.
- عقب‌افتادگیِ **اصلی (major)** → خودکار ننویس. برای هرکدام:
  1. یادداشتِ انتشار و راهنمای مهاجرتِ رسمی‌اش را بخوان (WebSearch/WebFetch).
  2. تصمیم بگیر: آیا کدِ این مخزن را نامنطبق می‌کند؟
  3. اگر بله → **اول** ورودیِ `MIGRATIONS.md` را بنویس، بعد پین را عوض کن (SELF-02).
  4. اگر نه → فقط پین و یک خط در CHANGELOG.
- جدولِ §۴ در `FULLSTACK.md` باید با `stack.json` بخواند — `self-check.py` این را می‌گیرد.

## ۳. بازنگریِ محتوایی (فقط در حالت `full`)

با WebSearch اینها را بسنج و **فقط با شاهدِ واقعی** تغییر بده:
- قاعده‌ای که پشتش عوض شده (مثلاً معیارِ کارایی، سطحِ WCAG، توصیه‌ی امنیتیِ منسوخ).
- الگویی که حالا استاندارد شده و در دستورالعمل نیست.
- قاعده‌ای که دیگر به کار نمی‌آید → حذف (SELF-04).

منابعِ معتبر: مستندِ رسمیِ خودِ ابزار، OWASP، W3C/WCAG، web.dev، یادداشتِ انتشارِ رسمی.
پستِ وبلاگ و نظرِ شخصی مبنای تغییرِ قاعده نیست.

> **دستورالعمل با هر بار اجرا بزرگ‌تر نمی‌شود.** قاعده‌ی تازه فقط از یک باگِ واقعی یا
> یک تغییرِ واقعیِ صنعت می‌آید (SELF-04). اگر چیزی برای گفتن نداری، چیزی اضافه نکن.

## ۴. بستنِ نسخه

1. نسخه‌ی تازه: `YYYY.MM.N` — همان ماه یعنی `N` یکی جلو، ماهِ تازه یعنی `N=1`.
2. این چهار جا باید یکی باشند: سرآیندِ HTML و سرصفحه‌ی `FULLSTACK.md`،
   `stack.json`، `lock.json`.
3. ورودیِ `CHANGELOG.md`: افزوده / عوض‌شده / حذف‌شده + نسخه‌های پایه.
4. هر تغییری که کدِ موجود را نامنطبق می‌کند → ورودیِ `MIGRATIONS.md` با همان قالب
   (سطح، قاعده‌ها، تشخیصِ درگیری، گام‌ها، وارسی، راهِ برگشت).
5. **`lock.json` → `guideline_version` را جلو نبر.** آن مالِ کد است نه دستورالعمل؛
   با `/gl-migrate` جلو می‌رود. جلو بردنش اینجا یعنی مهاجرت‌ها بی‌صدا گم می‌شوند.
6. `python3 guidelines/self-check.py` باید سبز باشد.
7. کامیت:
   ```
   guideline: <نسخه‌ی قبل> → <نسخه‌ی تازه>

   <خلاصه‌ی تغییرها>
   مهاجرت: دارد/ندارد
   ```

## ۵. گزارش به کاربر

- چه نسخه‌هایی جابه‌جا شد
- چه قاعده‌ای عوض/اضافه/حذف شد و چرا
- **آیا مهاجرت لازم است؟ اگر بله، بگو `/gl-migrate` بزند.**
